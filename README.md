# FarmerDiary

---

### 1. **Авторизація та управління акаунтами**
   - **Реєстрація:**
     - Користувач може зареєструвати акаунт, ввівши свій email та пароль.
     - Пароль хешується перед збереженням у базу даних (`user`).
     - Якщо email вже існує, система видає повідомлення про помилку.
   - **Вхід:**
     - Користувач вводить email і пароль для входу.
     - Хеш пароля перевіряється з тим, що збережено в базі.
     - Успішний вхід дозволяє користувачу виконувати подальші дії (наприклад, розрахунки).
   - **Вихід:**
     - Користувач може вийти зі свого акаунта, після чого доступ до функціоналу розрахунків обмежується.
     - Інтерфейс оновлюється відповідно до статусу користувача (увійшов чи ні).

---

### 2. **Розрахунок зерна**
   - **Формула:**
     - Використовується формула:
       \[
       {Норма висіву (кг/га)} = Бажана густота стояння (шт/м²)×Маса 1000 насінин (г) / 1000
       \]
     - Загальна кількість зерна:
       \[
       Кількість зерна (кг) = Норма висіву (кг/га)×Площа (м²) / 10000
       \]
   - **Інтерфейс:**
     - Користувач вводить:
       - Площу (м²),
       - Маса 1000 насінин (г),
       - Бажана густота стояння (шт/м²).
     - Натискає кнопку для розрахунку.
   - **Результат:**
     - Після розрахунку результат відображається у вікні повідомлення.
     - Результат записується в таблицю `Crop`, яка містить:
       - Назва культури,
       - Площа,
       - Кількість зерна,
       - UserID (ідентифікатор користувача).

---

### 3. **Розрахунок добрив**
   - **Формула:**
     - Використовується формула для розрахунку норми азотних добрив:
       \[
        Потрібна кількість азоту на га (кг/га)=(Бажана урожайність (т/га)×30)−Вміст азоту в ґрунті (кг/га)
       \]
       - Якщо значення менше 0, результат обмежується 0 (немає потреби у додатковому азоті).
     - Кількість добрив:
       \[
      Кількість добрив (кг) = (Потрібна кількість азоту на га (кг/га) / Коефіцієнт використання азоту ) * (Площа (м²) / 10000)
       \]
   - **Інтерфейс:**
     - Користувач вводить:
       - Площу,
       - Бажану урожайність,
       - Вміст азоту в ґрунті,
       - Коефіцієнт використання азоту.
     - Натискає кнопку розрахунку.
   - **Результат:**
     - Відображається кількість необхідних добрив.
     - Результат записується в таблицю `Fertilizer`, яка містить:
       - Тип добрива ("Азотне добриво"),
       - Площа,
       - Кількість добрив,
       - CropID (зв’язок із записом у таблиці `Crop`).

---

### 4. **База даних**
   - Проєкт використовує базу MySQL із наступними таблицями:
     - **`user`:**
       - `UserID` (PK),
       - `Email` (унікальний),
       - `PasswordHash`.
     - **`crop`:**
       - `CropID` (PK),
       - `Name` (наприклад, "Пшениця"),
       - `Area` (площа у м²),
       - `Quantity` (кількість зерна у кг),
       - `UserID` (FK до `user`).
     - **`fertilizer`:**
       - `FertilizerID` (PK),
       - `CropID` (FK до `crop`),
       - `Type` (наприклад, "Азотне добриво"),
       - `Amount` (кількість добрив у кг).

---

### 5. **Головний інтерфейс програми**
   - **Вкладки:**
     - "Акаунт":
       - Реєстрація,
       - Вхід,
       - Вихід.
     - "Розрахунок зерна та добрив":
       - Введення параметрів для розрахунку зерна та добрив.
       - Відображення результатів у повідомленні.
   - **Динамічний інтерфейс:**
     - При вході:
       - Відображається секція виходу та дані залогіненого користувача.
     - При виході:
       - Секція для входу/реєстрації стає доступною.

---

### 6. **Логіка збереження даних**
   - Всі розрахунки зберігаються в базу даних, щоб користувач міг відстежувати свої дані:
     - Кількість зерна (`Crop`),
     - Кількість добрив (`Fertilizer`).
